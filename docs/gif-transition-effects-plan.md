# GIF 切换效果扩展计划

本文档规划首版 GIF 效果之外的趣味切换效果，不改变现有 GIF 导出任务的基础配置和验收标准。

## 候选效果

| 效果 | 视觉表现 | 适合场景 | 优先级 |
| --- | --- | --- | --- |
| 像素溶解 | 当前徽章逐渐变成小方块，下一枚从方块中出现 | 最有 GIF 感、强调收藏变化 | P1 |
| 故障闪烁 | RGB 偏移、横向抖动和噪点后切换 | 科技感、稀有徽章 | P1 |
| 翻牌 | 徽章绕 Y 轴翻转，翻面后显示下一枚 | 卡牌、收藏册风格 | P1 |
| 弹跳登场 | 新徽章从小尺寸弹到正常大小并轻微回弹 | 活泼、游戏感 | P1 |
| 旋转切换 | 当前徽章缩小并旋转消失，下一枚旋转进入 | 快节奏轮播 | P2 |
| 圆形擦除 | 从中心向外扩散圆形遮罩，揭示下一枚 | 简洁、干净 | P2 |
| 上下滑动 | 当前徽章向上移出，下一枚从下方进入 | 竖向翻阅列表 | P2 |
| 闪光揭示 | 高光扫过画面后变成下一枚 | 金色、紫色等高稀有度徽章 | P2 |
| 模糊聚焦 | 当前徽章变模糊，下一枚逐渐清晰 | 柔和、高级 | P2 |
| 波纹扩散 | 从中心产生波纹，下一枚跟随波纹出现 | 魔法、潘多拉主题 | P2 |

## 推荐开发顺序

1. 像素溶解
2. 故障闪烁
3. 翻牌
4. 弹跳登场
5. 闪光揭示

## 实现约束

- 复用现有 `GifEffect`、过渡计划和实时预览机制。
- 每个效果继续使用 4–8 个过渡采样帧，并遵守过渡时长与 10 MB 文件体积限制。
- GIF 不支持真实 CSS 3D、滤镜和遮罩；翻牌、故障、像素溶解应在 Canvas 中逐帧绘制。
- 预览效果应与最终编码结果保持一致的视觉逻辑。
- 默认仍使用直接切换，新效果作为可选项保存。
- 设置面板效果较多时，按“基础、方向、趣味”分组展示。

## 验收标准

- [ ] 每种效果都能在生成前通过预览明确区分。
- [ ] 400 ms 间隔下徽章仍清晰可辨。
- [ ] 最后一枚切回第一枚时无明显停顿或闪烁。
- [ ] 2、8、12 帧下总时长与摘要一致。
- [ ] Chrome、Safari、Firefox 和常见图片查看器均可正常循环播放。
- [ ] 低端设备上生成期间仍可取消。
